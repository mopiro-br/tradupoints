# Tradupoints website

Crie uma landing page de alta performance, com design moderno e focado em conversão. Use HTML semântico, tipografia forte e hierarquia clara. Inclua um hero impactante, blocos de benefícios, prova social e um CTA destacado, otimizada para velocidade, responsividade e usabilidade.
O site é para empresa Tradupoints. A Tradupoints oferece serviços de tradução simultânea para eventos médicos, científicos e técnicos de alta complexidade. Atuamos como parceira estratégica de agências e empresas, garantindo precisão, clareza e segurança em cada apresentação. Com experiência em simpósios, congressos científicos, treinamentos internacionais e lançamentos de produtos, nossa equipe assegura que cada evento aconteça sem imprevistos e com total confiabilidade.
